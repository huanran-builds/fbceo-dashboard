# Super Neighborhood 41 Air Quality Dashboard

A live dashboard that turns raw PurpleAir PM2.5 sensor readings into a
neighborhood-facing view of air quality for Fort Bend County's Super
Neighborhood 41. Built and maintained as Environmental Data Intern at the
Fort Bend County Environmental Organization (FBCEO).

Built by: Huanran Yu. GitHub: huanran-builds

## What this does
Ingests PurpleAir PM2.5 data for SN41, [cleans/processes sensor readings],
and presents current and trending air quality in a form residents can read
without any technical background — so people can see when their air is unsafe
in real time.
